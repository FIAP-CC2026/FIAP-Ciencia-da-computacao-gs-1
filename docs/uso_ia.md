# Uso de IA

Usamos IA como apoio em três pontos:

- gerar as ocorrências fictícias do `data/dados.csv`, que depois ajustamos para ter as 4 categorias, os 3 status e dois registros com erro;
- tirar dúvidas de Python, como ler o CSV sem biblioteca e montar a matriz com lista de listas;
- revisar o texto do README e do relatório.

Para conferir, rodamos `python src/sistema.py` e testamos cada opção do menu, inclusive os casos de erro (cadastro sem categoria, código que não existe, status desconhecido). Os indicadores foram conferidos fazendo as contas na mão, por exemplo o tempo médio de 39 dias dividido por 6 concluídas, que dá 6,5 dias.
